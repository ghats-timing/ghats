# GHATS v3.4.0 -  Major Feature Release

This release represents a major expansion of **GHATS** since **v3.3.0**, introducing important new scientific capabilities, extending support to additional X-ray missions, modernizing core analysis routines, and providing comprehensive new documentation.

The headline addition is a comprehensive framework for **bispectral timing analysis**, integrated into the existing GHATS workflow. Alongside this, the release broadens mission support, improves the handling of Fourier products and metadata, and substantially expands the user documentation.

---

## What's New

This release introduces bispectral timing analysis, adds support for Einstein Probe and IXPE, modernizes the core timing-analysis pipeline, and provides a comprehensive new user manual. Together, these additions represent the largest functional expansion of GHATS since the public release of version 3.3.0.

---

# Highlights

- **New bispectrum and bicoherence analysis framework**
- **Support for Einstein Probe and IXPE**
- Improved support for RXTE, AstroSat, Insight-HXMT, NICER, NuSTAR, Swift, and XMM-Newton
- Modernized FFT, power-spectrum, and cross-spectral analysis
- Comprehensive new GHATS User Manual
- New GHATS File Format Specification
- Expanded built-in help system

---

# New Scientific Capabilities

## Bispectral Timing Analysis

This release introduces a comprehensive framework for higher-order Fourier timing analysis.

New functionality includes

- one- and two-dimensional bispectrum computation;
- bicoherence and normalized bispectral products;
- cross-bispectrum analysis;
- hypotenuse-domain bispectral analysis;
- frequency-band, Lorentzian-pair, and target-pair selection tools;
- two-dimensional visualization and adaptive rebinning;
- FITS input and output for bispectral products.

These additions extend GHATS beyond traditional power-spectrum and cross-spectral analysis, enabling the study of non-linear variability, harmonic coupling, and phase coupling within a unified timing-analysis environment.

---

## Expanded Mission Support

Support has been added for

- **Einstein Probe**
- **IXPE**

including mission-specific event reading, channel selection, automatic determination of time resolution, and extraction of instrument-specific metadata.

Support has also been updated and improved for

- RXTE
- AstroSat (CZTI and LAXPC)
- Insight-HXMT
- NICER
- NuSTAR
- Swift
- XMM-Newton

providing greater consistency across all supported missions and simplifying the development of mission-independent analysis workflows.

---

# Improvements to the Analysis Pipeline

Many core routines have been revised to improve robustness, consistency, and interoperability throughout the GHATS analysis chain.

Major improvements include

- improved FFT-header handling;
- standardized metadata throughout the pipeline;
- support for larger FFT products;
- improved quick-look products;
- enhanced handling of power-spectrum metafiles;
- improvements to averaging and rebinning;
- updated plotting routines;
- improvements to XSPEC interfaces;
- refinements to Poisson-noise estimation.

Cross-spectral analysis has also been substantially updated, with improvements to

- cross-spectrum production;
- real and imaginary cross spectra;
- metadata handling;
- compatibility with the expanded GHATS workflow.

These changes improve both reliability and consistency while maintaining compatibility with existing GHATS analysis procedures.

---

# Documentation

A major effort has gone into making GHATS easier to learn, use, and maintain.

This release introduces a comprehensive LaTeX-based **GHATS User Manual**, covering

- installation;
- quick-start tutorials;
- FFT and power-spectrum production;
- reading, averaging, and rebinning products;
- dynamic power spectra;
- cross-spectral analysis;
- plotting;
- XSPEC workflows;
- GHATS file formats;
- conversion notes;
- revision history.

In addition, the repository now includes a standalone **GHATS File Format Specification**, providing a detailed reference for the GHATS binary data products and metadata conventions.

---

# Help System

The internal help system has been substantially expanded.

New features include

- searchable help keywords;
- alphabetical routine index;
- task-oriented routine index;
- improved command-line help utilities;
- expanded routine documentation;
- additional documentation for AstroSat CZTI routines.

These improvements make it considerably easier to discover existing functionality and navigate the growing GHATS code base.

---

# Contributed Utilities

Several new utilities have been added, including tools for

- generating FFT products from ASCII light curves;
- splitting FFT files;
- splitting power-spectrum files;
- concatenating power-spectrum products;
- estimating Poisson-noise levels over selected frequency ranges.

---

# Internal Improvements

This release also includes numerous internal improvements throughout the code base, including

- code cleanup and refactoring;
- improved compilation consistency;
- enhanced metadata management;
- repository reorganization;
- infrastructure updates that improve portability and long-term maintainability.

Although largely invisible to users, these changes provide a stronger foundation for future development.

---

# Summary

GHATS v3.4.0 significantly expands the scientific capabilities of the package while improving usability, documentation, portability, and long-term maintainability.

The introduction of a comprehensive bispectral analysis framework, together with support for Einstein Probe and IXPE and a fully revised user manual, makes this the largest functional expansion of GHATS since version 3.3.0.

We thank all GHATS users for their continued feedback and support, and hope these additions make GHATS an even more powerful and accessible environment for high-time-resolution X-ray timing analysis.
