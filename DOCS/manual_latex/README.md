# GHATS LaTeX Manual Source

This directory is the starting point for a LaTeX version of the GHATS manual.

The intended workflow is:

1. Keep the legacy Pages, Word, and PDF manual files in `DOCS/Manual/`.
2. Use the Word document as the main text source.
3. Use `Manual_3.3.0.pdf` as the visual/style reference.
4. Convert and review the manual one chapter at a time.

The current files are a skeleton plus an initial title page and front matter.
