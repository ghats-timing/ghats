\chapter{Routine Reference}

This chapter gives a compact directory of the main user-facing routines.  It
should be kept consistent with \routine{gh_help} and each routine's
\keyword{HELP} output.

\section{Directory of Routines}

This directory is the first place to look for the name of a routine.  It gives
one line per command, grouped by task.  Once the relevant command has been
identified, run it with \keyword{HELP} for detailed syntax:

\begin{ghatsconsole}
Ghats> gh_cs, /help
\end{ghatsconsole}

The same directory can be opened inside GHATS with:

\begin{ghatsconsole}
Ghats> gh_help, /task
Ghats> gh_help, /alpha
\end{ghatsconsole}
