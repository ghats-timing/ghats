\chapter{Conversion Notes}

The legacy manual was authored in Apple Pages and exported to Word and PDF.
The LaTeX version should use:

\begin{itemize}
\item the Word document as the main source of recoverable text;
\item the PDF as the visual reference for layout and style;
\item the current routines and \routine{gh_help} output as the source of truth
  for command behavior.
\end{itemize}

\begin{ghatsnote}
Do not change scientific definitions, Fourier conventions, lag sign
conventions, normalization conventions, or file formats during manual
conversion. Any such change must be discussed separately.
\end{ghatsnote}
