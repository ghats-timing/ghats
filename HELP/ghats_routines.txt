# GHATS Routine Directory

First place to look for available GHATS routines and their purpose.
Use `gh_help` inside GHATS/IDL, or open this file directly with `less`.
Inside `less`, search with `/text`, for example `/coherence` or `/xspec`.

This is a curated public/semi-public index, not a list of every internal helper.
After choosing a routine, run it with `/help` for detailed usage, for example:
`gh_cs,/help`

## By Task

### Start Here

gh_help                         HELP              Open this routine directory in a pager.
gh_version                      ANALYSIS          Print the GHATS version string.
gh_info                         ANALYSIS          Print basic header information for a GHATS PDS or FFT file.
ghats_all                       ANALYSIS          Produce a quick summary plot/report from a PDS file.
